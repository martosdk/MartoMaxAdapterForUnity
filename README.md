# MartoMaxAdapterForUnity

AppLovin MAX mediation custom adapter for MartoSDK, packaged for Unity.

## Requirements

- iOS 13.0+
- [MartoSDK](https://github.com/martosdk/MartoSDK-iOS) 1.11.0
- AppLovin MAX (Unity)

## Installation

Import `MartoMaxAdapterForUnity.unitypackage` into your Unity project
(Assets > Import Package > Custom Package), then include it together with
MartoSDK and the AppLovin MAX Unity plugin.
